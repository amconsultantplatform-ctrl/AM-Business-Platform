# Final Accounting Certification Evidence

The accounting certification is produced by:

```text
npm run test:final-accounting-certification
```

It covers first-run accounting setup, canonical financial-event posting,
commercial operations, product reconciliation, fiscal closing, real exports,
browser acceptance, and dependency security.

The report is not a production sign-off by itself. Any unavailable or
unverified external provider or target-environment requirement remains open
until runtime evidence is supplied.
